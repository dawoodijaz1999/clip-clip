# clip-clip

Paste a YouTube link in the Discord channel. Within ~10-30 minutes the bot replies with
5 vertical (1080x1920) clips of 30-60 seconds, each with a hook line on top and a TikTok caption.

Secrets: `DISCORD_BOT_TOKEN`, `GEMINI_API_KEY`, `YT_COOKIES` (cookies.txt of a throwaway Google account).
